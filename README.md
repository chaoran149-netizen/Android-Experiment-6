# Android 实验六 多Fragment应用

陈浩然 · 2024110203 · 2024级2班

应用包含玩家档案、两张牌游戏和三张牌游戏。三个页面分别使用私有文件保存资料和牌局状态，重新打开应用后可继续。

在 Android Studio 打开仓库根目录，配置 JDK 17 与 Android SDK 35，运行 app。也可以执行 `gradlew.bat :app:assembleDebug`。
